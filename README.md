# Skorly.id

**Dari soal, langsung jadi nilai.** — Platform ujian online yang membantu guru menyiapkan ujian dalam satu ruang. Murid masuk dengan token, jawaban dinilai otomatis, dan hasilnya langsung siap dibaca.

## 📸 Preview

![Landing Page Skorly.id](docs/landing-preview.png)

## 📁 Struktur Project

Struktur project dipisahkan berdasarkan aplikasi:

- `frontend/` — aplikasi React + Vite untuk antarmuka Skorly.id.
- `backend/` — tempat API dan layanan server yang akan ditambahkan nanti.

## 🚀 Menjalankan Frontend

```bash
cd frontend
npm install
npm run dev
```

Build production juga dijalankan dari folder `frontend` dengan `npm run build`.
