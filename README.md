# Skorly.id

Struktur project dipisahkan berdasarkan aplikasi:

- `frontend/` — aplikasi React + Vite untuk antarmuka Skorly.id.
- `backend/` — tempat API dan layanan server yang akan ditambahkan nanti.

## Menjalankan frontend

```bash
cd frontend
npm install
npm run dev
```

Build production juga dijalankan dari folder `frontend` dengan `npm run build`.
